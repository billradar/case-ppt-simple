# case-ppt-simple

病例汇报 PPT 的**保守改造**方案：**骨架不动，内容与文字随意编辑。**

- **骨架零改动**：不改页面尺寸/主题/背景/Logo/母版/版式/页眉页脚/页码/页序/动画；不改表格与图片以外原对象的几何。
- **内容与文字自由**：文字可改写增删；字体、字号、字重、颜色、对齐、行距、缩进、项目符号都可改。
- **表格与图片可编辑**：既有表格（改内容、增删行列、改格式、移动缩放）与图片（替换、裁剪、缩放）都可直接改。
- **可新增**：图片、表格、文本框、形状，放在空白区。
- **内容可生成**：可自行编写去标识化教学病例。
- **命名规范**：交付文件统一命名为 `NAME-科室-病例汇报.pptx`。

## 适用场景

- 医院/科室有固定 PPT 模板，只允许**改内容**，不允许改整体设计（主题、母版、版式、页序）。
- 需要把一段文字改清楚、把化验变成表格、替换/补充图片、修正字体字号与配色。
- 希望在保留模板整体观感的同时，把内容与文字打磨到位。

## 与姊妹项目的关系

| 项目 | 定位 | 编辑范围 |
| --- | --- | --- |
| [case-report-ppt](https://github.com/billradar/case-report-ppt) | 疾病内容重构、重排版 | 可重排卡片/分栏/证据链，改结构（level 2） |
| **case-ppt-simple**（本项目） | 保守：骨架不动、内容与文字自由 | 不改主题/母版/版式/页序/动画；文字、格式、表格、图片可改 |

两者独立使用；本项目不并入 `case-report-ppt`。

## 使用

1. 用 OpenCode 加载 [SKILL.md](SKILL.md) 与其 `references/` 下的文件。
2. 编辑前先复制源 PPT 为工作副本，只改副本。
3. 按 [references/validation.md](references/validation.md) 逐项核对"骨架零改动"。
4. 交付为 `NAME-科室-病例汇报.pptx`，交付后删除工作副本。

## 目录结构

```text
SKILL.md                      主入口：铁律、默认决策、交付
AGENTS.md                     给自动化代理的简明约束
references/
  workflow.md                 工作流：复制、盘点、编辑、增页、交付
  layout-design.md            允许改什么、禁止改什么、新增元素怎么放
  medical-content.md          内容生成、一致性与脱敏
  powerpoint-technical.md     工具操作与禁用清单
  validation.md               完成前的逐项核对清单
  examples.md                 允许/禁止的具体例子
```
