# 保守质检（完成前逐项核对）

## 内容检查

- [ ] 全篇数据自洽：数值、单位、参考范围、日期、诊断名称前后一致。
- [ ] 初步/鉴别/最终诊断分层清楚；治疗与转归自洽。
- [ ] 已脱敏（如用真实资料）：文字、截图、影像角标、页眉页脚、备注、图片替代文本、文件属性。
- [ ] 幻灯片任何位置不出现"教学病例模拟数据/模拟数据/仅用于演示"等字样。
- [ ] 交付文件名符合 `NAME-科室-病例汇报.pptx`。

## 模板保真检查（本项目重点）

- [ ] **逐个原对象**核对：`left/top/width/height` 与基线完全一致（未移动、未缩放、未旋转）。
- [ ] **逐个原对象**核对：字体名、字号、字重、颜色、对齐、行距、缩进、项目符号与基线一致。
- [ ] 原对象的填充、边框、阴影、效果未被改动。
- [ ] 母版、版式、主题、主题色、背景、Logo、页眉页脚、页码未被改动。
- [ ] 页数、页序未变（授权增页除外；增页复用相同版式）。
- [ ] 动画与切换未被增删。

## 新增元素检查

- [ ] 每个新增元素都是"新的独立对象"，未修改原对象。
- [ ] 新增元素不覆盖、不遮挡、不重叠原文；位置在空白区。
- [ ] 新增元素字体族、字号层级与全篇一致；正文不低于 16 pt。
- [ ] 表格/图片清晰可读；表格行列数按内容需要，不强凑。

## 技术检查

- [ ] 逐页查看渲染图，并抽查原对象属性（文本、几何、字体）。
- [ ] 最终 `.pptx` 可关闭后重新打开；页数、页序、关键对象未丢失。
- [ ] 放映可正常进入；动画/切换（若有）未变、不阻塞讲解。
- [ ] 最终文件不是源文件或临时文件；`_working` 副本在交付后删除。
