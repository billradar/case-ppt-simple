# 保守质检（完成前逐项核对）

## 内容检查

- [ ] 全篇数据自洽：数值、单位、参考范围、日期、诊断名称前后一致。
- [ ] 初步/鉴别/最终诊断分层清楚；治疗与转归自洽。
- [ ] 异常值/关键证据已用 `#EE0000` 标注，只标数值、不整段染红。
- [ ] 已脱敏（如用真实资料）：文字、截图、影像角标、页眉页脚、备注、图片替代文本、文件属性。
- [ ] 幻灯片任何位置不出现"教学病例模拟数据/模拟数据/仅用于演示"等字样。
- [ ] 交付文件名符合 `NAME-科室-病例汇报.pptx`。

## 骨架保真检查（本项目重点）

- [ ] 页面尺寸/比例、主题、主题色、主背景、Logo 未变。
- [ ] 母版、版式、页眉页脚、页码体系未变。
- [ ] 页数、页序未变（授权增页除外；增页复用相同版式）。
- [ ] 动画与切换未被增删。
- [ ] **表格与图片以外的原有对象**：`left/top/width/height/rotation` 与基线完全一致（未移动、未缩放、未旋转、未删除、未组合/解组）。

## 允许改动的检查

- [ ] 文字已按要求更新；字体、字号、字重、颜色、对齐、行距、缩进、项目符号符合预期。
- [ ] 改动后未溢出文本框；必要时已按规则调整字号（≥16 pt）或行距，或改为新增页。
- [ ] 既有表格/图片的改动符合预期，且未越出可用区、未压住页眉页脚与页码。

## 新增元素检查

- [ ] 每个新增元素都是新的独立对象，未修改原对象。
- [ ] 新增元素不遮挡、不重叠既有内容；位置在空白区。
- [ ] 新增元素字体族、字号层级与全篇一致；正文不低于 16 pt。
- [ ] 表格/图片清晰可读；行列数按内容需要，不强凑。

## 技术检查

- [ ] 逐页查看渲染图，并抽查文本、几何、字体。
- [ ] 最终 `.pptx` 可关闭后重新打开；页数、页序、关键对象未丢失。
- [ ] 放映可正常进入；动画/切换（若有）未变、不阻塞讲解。
- [ ] 最终文件不是源文件或临时文件；`_working` 副本在交付后删除。
