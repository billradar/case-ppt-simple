# 具体改造示例（保守版）

以下示例均为虚构、去标识化教学信息，数字仅示意。

## 示例 1：用"新增表格"承载检验（不改原表）

**做**：原页有一张密集指标表或一大段化验文字。保持原对象不动，在其下方的空白区**新增**一张表格：

```text
| 项目     | 结果            | 参考范围   |
| -------- | --------------- | ---------- |
| WBC      | 16.8×10⁹/L ↑    | 3.5–9.5    |
| CRP      | 86 mg/L ↑       | < 8        |
| PLT      | 420×10⁹/L ↑     | 125–350    |
```

**不做**：不修改原表格/文本框，不移动它们，不给整页换配色。

## 示例 2：现病史放不下 → 新增一页（不改原页）

**做**：原页文字过长、换行难看。保持原页不动，**复制一页**（继承完全相同版式），把部分内容编入新页；两页版式一致。

**不做**：不缩小原页字号，不拉高文本框，不删原页。

## 示例 3：就地改字，保留格式

**做**：把原文本框里的一整段替换为要点，但**只改文字**，原字体、字号、颜色、项目符号不动：

```text
改前：患儿于入院前5天无明显诱因出现发热，体温最高达39.5℃……（一段长文）
改后：• 入院前5天：发热，Tmax 39.5℃，热型不规则
      • 入院前2天：皮疹、结膜充血、口唇皲裂、手足硬肿
      • 院外按"上呼吸道感染"治疗无效
```

**不做**：不改成新字体、不缩字号、不换颜色、不把整段染红。

## 示例 4：新增图片作为示意

**做**：在不遮挡原文的位置**新增**一张示意图（如川崎病诊断流程图），可加一个新增文本框作图注。

**不做**：不替换原图、不裁剪原图、不改变原图尺寸。

## 明确禁止（反例）

- 缩小字号让文字塞进原文本框。
- 拖动/缩放原文本框或图片。
- 给整页换主题色、换字体、换背景。
- 删除原始对象"腾地方"。
- 增删动画或切换。
