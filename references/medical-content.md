# 内容生成与一致性（保守版）

本项目**允许自行生成、补全病例内容**。文字与文本格式可自由编辑，但生成内容仍要自洽、可讲。

## 内容可以生成的地方

- 基本资料（去标识化年龄段、性别、相对时间线）
- 主诉、现病史、既往史、个人史
- 查体（阳性与关键阴性体征）
- 辅助检查（血常规、炎症指标、生化、影像、心电图等）
- 诊断与鉴别诊断
- 治疗经过与转归、随访计划
- 全科思考、困难与不足

## 先建统一数据源

虽是生成内容，仍建议先写结构化草稿再填入页面，保证全篇一致：

| 模块 | 建议字段 |
| --- | --- |
| 基本资料 | 年龄段、性别、入院/起病相对时间 |
| 主诉与现病史 | 症状、起病、病程、关键阴阳性、时间点 |
| 既往史/过敏史 | 相关风险因素、否认项 |
| 查体 | 阳性体征、关键阴性体征、时点 |
| 辅助检查 | 名称、值、单位、参考范围、时点 |
| 诊断 | 初步/最终诊断、鉴别诊断与依据 |
| 治疗与转归 | 措施、剂量/频率、观察结果、时间 |
| 反思 | 问题、原因、改进 |

## 一致性检查

1. 日期按病程先后排列，"入院、检查、干预、复查、出院"互不矛盾；
2. 数值、单位、参考范围、异常方向在各页一致；
3. 初步诊断、鉴别诊断、最终诊断分层清楚；
4. 用药剂量与适应证自洽；
5. "无/正常/治愈"等绝对措辞有对应描述支撑。

## 标红约定

- 异常指标、关键阳性证据、最终诊断的关键短语用 `#EE0000`。
- 只标关键数值/短语，不整段、整表染红；数值旁保留单位与（已知的）参考范围、采集时点。

## 脱敏

- 生成内容不得映射到真实个人。
- 如使用真实资料：删除姓名、照片、证件号、联系方式、住址、精确生日、病案号、条码、完整住院号及截图中的同类信息；影像角标、页眉页脚、备注与图片替代文本同样检查。
- 年龄用区间或"××岁"；时间可相对化为"入院第 N 天"。

## 幻灯片措辞

- 幻灯片（正文、页脚、备注、图片替代文本）**不出现**"教学病例模拟数据""模拟数据""仅用于演示/病例汇报演示"等字样；如需说明数据性质，只写在交付说明里。
