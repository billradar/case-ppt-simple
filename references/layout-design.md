# 排版约束（保守版）

`layout_change_level` 固定为 **0：完全保持原 Layout**。

## 可以做的

- 在**既有文本框**内替换文字，保留原字体、字号、颜色、对齐、行距、缩进与项目符号。
- **新增**独立对象到空白区：
  - 表格（承载检验、鉴别诊断等结构化信息）；
  - 图片（示意图、流程图截图、影像图）；
  - 文本框/形状（补充说明、图注）。
- 新增元素可自带样式，但只影响**该新对象**，不触碰任何原对象。

## 不能做的

- 移动、缩放、旋转、删除、组合/解组任何原对象。
- 改字体/字号/字重/颜色/对齐/行距/缩进/项目符号。
- 改形状的填充、边框、阴影、效果。
- 改母版、版式、主题、主题色、背景、Logo、页眉页脚、页码、页序。
- 增删动画与切换。

## 新增元素摆放原则

- 放在既有内容的**空白区**，与周边对象保持可辨留白，不遮挡、不重叠。
- 同一份汇报内，新增对象样式保持一致：同一字体族、相近字号层级、同一圆角/线宽。
- 字号：标题约 24 pt、小标题约 20 pt、正文约 18 pt，正文不低于 16 pt。
- 新增表格：表头加底色、行间可用浅色带分隔即可，不必套用与全篇不同的花哨样式。

## 异常值强调（可选）

- 本保守版**默认不做任何着色**。
- 仅当用户明确要求标注异常值时，才对既有文字里的关键数值 run 设 `#EE0000`；不改字号、字体、位置，也不整段染红。

## 与"重排版版"的分工

- 需要重排卡片/分栏/证据链、调整层级 → 用 `case-report-ppt`。
- 只想在不惊动模板的前提下把内容补齐、加图表 → 用本项目。
