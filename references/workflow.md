# 保守工作流（只增不改）

## 1. 接收与边界确认

- 确认源文件、最终文件名、授权范围（是否允许增页）、交付路径。
- 明确本项目的默认边界：**排版与格式零改动**，只做"就地改字 + 新增元素"。
- 内容来源：可以自行生成/补全教学病例；如使用真实资料，先做脱敏。

## 2. 保护原件：先复制，后编辑副本

```text
源 PPT（只读基线）
  → 打开/检查，记录基线
  → 立即另存为工作副本
  → 只编辑该副本；原件永不改动
```

- 建议命名：`NAME-科室-病例汇报_working.pptx`；最终版 `NAME-科室-病例汇报.pptx`。
- 若源文件已被 AutoSave 改动，先停止、保留现状、从版本历史恢复后再建副本。

## 3. 基线盘点（决定"不能动什么"）

逐页记录：

- 每个对象的 `left/top/width/height`、字体、字号、颜色、对齐；
- 母版/版式、背景、Logo、页眉页脚、页码、页序；
- 文本框当前文字与其段落/项目符号格式；
- 图片、表格、图表、组合对象、动画与切换。

把上述存成基线快照，改完后逐项比对（见 [validation.md](validation.md)）。

## 4. 内容生成与统一数据源

- 可自行生成病例内容；仍建议先写一份结构化草稿统一数值、单位、日期、诊断名称，再填入页面，避免前后矛盾。
- 生成内容不得影射真实个人；如用真实资料，删除姓名、证件、联系方式、病案号、精确生日等。

## 5. 两类允许的改动

**A. 就地改字**（不改格式）

- 用"最小范围替换"改文字：只改目标 run 的文本，保留其 `rPr`（字体/字号/颜色/字重）。
- 不要用"整体重写形状文本"的接口（会重置格式）。技术细节见 [powerpoint-technical.md](powerpoint-technical.md)。

**B. 新增元素**（放在空白区）

- 需要表格/图片时**新增**独立对象，不修改既有对象。
- 新增对象不要压住原文；与全篇字体族、字号区间保持一致。

## 6. 溢出与放不下

1. 先精简文字（保持原格式，只改内容）；
2. 仍不够，则**新增一页**：复制一个既有页以继承完全相同版式，再填内容；
3. 绝不缩小字号、绝不移动/缩放原对象。

## 7. 渐进保存与失败恢复

- 每完成一页或一小批就保存工作副本；重大新增前生成带时间戳的恢复点。
- 一次只做可验证的改动；失败时撤销当前小批次，不在损坏文件上叠加修补。

## 8. 最终化

- 执行 [validation.md](validation.md) 的内容、保真、技术检查；确认"原对象几何与格式未变"。
- 定名 `NAME-科室-病例汇报.pptx`；交付后删除工作副本。
