# 病例库（case-library）

高质量、结构化、可直接选用的**去标识化教学病例**集合。用于快速填充病例汇报，无需从零编写。

## 用途与选用规则

1. **先匹配**：按用户给出的科室 / 病种 / 人群，在下方索引中匹配最接近的病例。
2. **匹配到就直接用**：采用该病例的病史、查体、检验、诊断、治疗与转归；数值可微调，但同一份汇报内必须自洽。
3. **未匹配到**：
   - 取库内同科室、同系统的病例改造（换病种、换关键检查与治疗）；或
   - 以库内模板结构现场生成（本项目允许生成内容，见 [medical-content.md](medical-content.md)）。
4. **一致性核对**：写完全篇后核对数值、单位、参考区间、日期、诊断名称前后一致。
5. **尊重项目边界**：
   - 保守项目 `case-ppt-simple`：病例内容**只用于填充既有版式**，不得为容纳内容而改动模板骨架。
   - 重排版项目 `case-report-ppt`：可按医学叙事重排，但保留模板视觉语言。
6. **脱敏**：库内病例已是去标识化；若把真实资料混入，先删除标识信息。

## 扩展病例库

1. 复制 `cases/_TEMPLATE.md` 为 `cases/<科室>-<病种>.md`，按模板填写。
2. 在上方索引表补一行（ID 规则：`科室缩写-病种缩写-序号`）。
3. 保持"证据链"完整：病史 → 体征 → 关键检查 → 排除 → 结论；关键检查必须有单位与参考区间。
