# 川崎病（皮肤黏膜淋巴结综合征）· 儿科

## 元信息

- ID：PED-KD-01
- 科室：儿科（小儿心血管）
- 病种：川崎病（皮肤黏膜淋巴结综合征）
- 人群：男，2 岁
- 关键教学点：持续发热≥5 天 + 5 项主要临床表现；IVIG 2 g/kg 一次静脉输注；阿司匹林抗血小板；冠状动脉随访
- 数据完整度：高

## 主诉

发热 5 天，伴皮疹 2 天。

## 现病史（时间线）

- 入院前 5 天：无明显诱因发热，Tmax 39.5℃，热型不规则；口服布洛芬可短暂下降，但反复升高。
- 入院前 2 天：全身散在红色皮疹（以躯干为主，无瘙痒）；双眼球结膜充血（无脓性分泌物）；口唇干燥皲裂、杨梅舌；双手足肿胀、发硬。
- 入院当天：精神稍差、食欲下降；曾在当地诊所按"上呼吸道感染"予抗病毒及对症治疗无效，为进一步诊治收入院。

## 既往史 / 个人史 / 过敏史

既往体健，无药物过敏史，无川崎病家族史；按期接种疫苗，无肝炎、结核等传染病接触史。

## 体格检查

- 生命体征：T 39.2℃，P 132 次/分，R 30 次/分，SpO₂ 98%；神志清，精神稍差。
- 阳性体征：全身散在红色多形性皮疹（躯干为主）；双眼球结膜充血；口唇干燥皲裂、口腔黏膜充血、杨梅舌；颈部淋巴结肿大（最大约 1.5 cm×1.5 cm，质中，轻压痛）；双手足肿胀、发硬。
- 关键阴性体征：无咳嗽咳痰，无呕吐腹泻，无抽搐，无关节肿痛；心肺、腹部及神经系统查体未见异常。

## 诊断

- 入院诊断：川崎病（皮肤黏膜淋巴结综合征）。
- 诊断依据（证据链）：持续发热≥5 天 → 具备双侧结膜充血、口唇及口腔改变（皲裂、杨梅舌）、多形性皮疹、四肢硬肿、颈部淋巴结肿大等主要表现（≥5 项）→ WBC/PLT/CRP/ESR 显著升高 → 排除其他发热出疹性疾病 → 川崎病。
- 鉴别诊断：

| 疾病 | 鉴别要点 |
| --- | --- |
| 猩红热 | 咽拭子 A 组 β 溶血性链球菌(+)，弥漫潮红、帕氏线、口周苍白圈 |
| 麻疹 | 卡他症状、口腔 Koplik 斑，皮疹按序出现，有接触史 |
| 幼年特发性关节炎 | 发热持续更久、关节炎表现明显，无结膜充血及手足硬肿 |
| 渗出性多形红斑 | 皮疹呈靶形/水疱，多累及黏膜，无持续高热 |
| 败血症 | 全身感染中毒症状重，血培养阳性，抗感染有效 |

## 治疗

- 免疫治疗：大剂量 IVIG 2 g/kg 一次静脉输注，阻断全身炎症反应、降低冠状动脉病变风险。
- 抗血小板：阿司匹林 30–50 mg/kg/d 分次口服，热退后减量至 3–5 mg/kg/d 维持。
- 对症支持：退热、补液，维持水电解质平衡；皮肤及口腔护理，预防感染。
- 心血管监测：定期复查心脏彩超、心电图，动态监测冠状动脉有无增宽或动脉瘤。

## 转归

输注后 24–48 小时体温逐渐降至正常；皮疹、结膜充血及手足肿胀逐渐消退。出院前复查心脏彩超未见冠状动脉病变，炎症指标明显下降，达出院标准。

## 随访

出院后 2 周、1 个月、2 个月、6 个月及 1 年复查心脏彩超及心电图；如发现冠状动脉异常，延长随访时间。继续口服阿司匹林，嘱按时服药、勿随意停药。

## 教学点 / 全科思考

- 川崎病是儿童后天性心脏病常见病因，早期识别、及时规范治疗对预防冠状动脉损伤至关重要。
- 全科医师需提高对"持续发热伴皮疹"患儿的警惕性，减少漏诊误诊。
- IVIG 与阿司匹林需严格掌握指征与用法用量；心脏彩超随访是评估远期预后的关键。
