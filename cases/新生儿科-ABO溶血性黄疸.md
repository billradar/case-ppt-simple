# ABO 溶血性黄疸（新生儿高胆红素血症）· 新生儿科

## 元信息

- ID：NEO-HDN-01
- 科室：新生儿科
- 病种：新生儿 ABO 血型不合性溶血病 / 新生儿高胆红素血症
- 人群：男，生后 3 天，胎龄 39+1 周
- 关键教学点：母婴血型不合 + Coombs(+) + 网织红升高构成溶血证据；光疗为主，IVIG/换血有严格指征；防胆红素脑病
- 数据完整度：高

## 主诉

生后 3 天，皮肤黄染进行性加重 2 天。

## 现病史（时间线）

- 生后第 1–2 天：颜面部及躯干皮肤黄染，进行性加重，逐渐发展至四肢及手足心；24–48 小时内明显进展。
- 生后第 3 天：可正常吮乳，无发热、呕吐、抽搐及呼吸急促；外院经皮胆红素（TcB）渐升至 18.5 mg/dL，总胆红素（TSB）320 μmol/L，以间接胆红素升高为主；无光疗及换血史。

## 既往史 / 个人史 / 过敏史

G2P1，足月顺产，出生体重 3200 g，入院体重 3050 g，Apgar 1 分钟 9 分、5 分钟 10 分；羊水清，胎膜完整，无胎膜早破。母孕期规律产检，无妊娠期高血压、糖尿病及感染史；无新生儿黄疸家族史。

## 体格检查

- 生命体征：T 37.0℃，P 140 次/分，R 42 次/分，SpO₂ 98%；神志清，反应可。
- 阳性体征：全身皮肤中度黄染（颜面、躯干及四肢近端为著），巩膜黄染；肝肋下 1.5 cm，质软。
- 关键阴性体征：无苍白、发绀、皮疹及出血点；心音有力、未闻及杂音；双肺呼吸音清；脾肋下未触及；原始反射存在，肌张力正常，无胆红素脑病早期表现。

## 诊断

- 入院诊断：① 新生儿溶血性黄疸；② 新生儿高胆红素血症；③ ABO 血型不合性溶血病。
- 诊断依据（证据链）：生后 24–48 小时内早期出现黄疸且进展快、以间接胆红素升高为主 → 母婴血型不合 → 直接 Coombs 试验阳性 → 网织红细胞升高提示溶血 → 无感染/缺氧等加重因素。
- 鉴别诊断：

| 疾病 | 鉴别要点 |
| --- | --- |
| 生理性黄疸 | 生后 2–3 天出现、进展慢、胆红素较低，Coombs 阴性 |
| 新生儿感染 | 伴发热、反应差、CRP/PCT 升高，血培养可阳性 |
| G6PD 缺乏 | 男性多见，氧化应激诱发，G6PD 活性降低，Coombs 阴性 |
| 新生儿肝炎 | ALT/AST 明显升高，以直接胆红素升高为主 |
| 胆道闭锁 | 直接胆红素持续升高，白陶土色大便，超声示胆囊异常 |

## 治疗

- 光疗：入院当日启动双面蓝光光疗（425–475 nm），强度≥30 μW/cm²/nm，每 6–12 小时监测 TcB/TSB；加强喂养、维持液体平衡。
- 免疫治疗：胆红素接近换血阈值，予 IVIG 1 g/kg 一次静脉输注。
- 支持治疗：按需母乳喂养，监测出入量、体重及血红蛋白。
- 重症处理：动态评估换血指征；本例未达换血标准，继续光疗及药物支持。

## 转归

光疗 48 小时后黄疸明显消退，TSB 降至 198 μmol/L，72 小时后降至 145 μmol/L；精神反应好，喂养量稳定增加，停光疗观察 24 小时无反弹，达出院标准。

## 随访

- 出院后 1 周、2 周复诊，监测黄疸消退、复查胆红素、评估体重与喂养。
- 1、3、6 月龄随访运动发育、听力筛查及神经系统表现，防范胆红素脑病后遗症。
- 健康宣教：指导家属识别黄疸早期表现，强调随访与母乳喂养重要性。

## 教学点 / 全科思考

- 新生儿黄疸需结合胎龄、日龄及危险因素综合判断；动态监测胆红素趋势。
- 早期识别溶血性黄疸对预防胆红素脑病至关重要；IVIG 及换血需严格掌握指征。
- 加强产儿协作，从孕期即关注血型不合等高危因素。
