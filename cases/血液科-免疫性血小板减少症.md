# 免疫性血小板减少症（ITP）· 血液科

## 元信息

- ID：HEM-ITP-01
- 科室：血液科
- 病种：免疫性血小板减少症（原发免疫性血小板减少症）
- 人群：女，14 岁
- 关键教学点：单一血小板减少必须先排除其他病因；激素 + rhTPO；诊断的"证据支持 + 排除"双基础
- 数据完整度：中

## 主诉

体检发现血小板减少 1 周。

## 现病史（时间线）

- 1 周前：体检血常规 PLT 41×10⁹/L，无发热、出血、乏力。
- 门诊：自身抗体阴性；骨髓涂片示增生性骨髓象、巨核细胞成熟障碍；病毒四项阴性。
- 入院：复查 PLT 33×10⁹/L，为进一步诊治收入院。

## 既往史 / 个人史 / 过敏史

既往无特殊病史，无出血倾向，无近期药物、感染诱因；家族无传染病史，个人史无异常。

## 体格检查

- 生命体征：BP 125/85 mmHg，HR 69 次/分，T 36.6℃，体重 80.5 kg。
- 阳性体征：发育正常、营养良好，未见明显异常体征。
- 关键阴性体征：无皮肤黏膜出血点、无肝脾肿大及淋巴结肿大。

## 诊断

- 入院诊断：免疫性血小板减少症（ITP）待排继发因素后确定。
- 诊断依据（证据链）：青年女性、体检发现血小板显著降低且无出血 → WBC/RBC/Hb 正常提示骨髓未受抑 → 骨髓涂片排除病理性改变 → 肝肾功能、腹部超声排除脾亢 → 自身抗体阴性不支持抗磷脂综合征 → 结合单纯血小板减少、无肝脾肿大、无明确诱因，符合 ITP。
- 鉴别诊断：

| 疾病 | 鉴别要点 |
| --- | --- |
| 病毒感染继发血小板减少 | 有感染史、可伴发热，病毒指标阳性，多自限 |
| 抗磷脂综合征 | 狼疮抗凝物/抗心磷脂/抗β2GP1 阳性，可伴血栓 |
| 脾功能亢进 | 脾大，多系三系受累 |
| 再生障碍性贫血 | 三系减少，骨髓增生低下 |
| TTP | 五联征、微血管病性溶血、神经症状 |

## 治疗

- 糖皮质激素：抑制异常免疫反应、减少血小板破坏、抑制自身抗体生成，稳定血管。
- rhTPO：模拟内源 TPO，刺激骨髓巨核细胞增殖成熟，增加血小板生成。
- 监测：定期复查血常规，观察出血倾向与药物不良反应。

## 转归

治疗后第 3 天 PLT 升至 102×10⁹/L，出院前复查 PLT 158×10⁹/L。

## 随访

门诊定期复查血小板与出血倾向；避免使用影响血小板功能的药物；病情变化及时复诊。

## 教学点 / 全科思考

- 诊断 ITP 必须先系统排除感染、药物、肝脾疾病、造血系统及自身免疫病等病因。
- 规范的排除流程避免误诊与不必要的治疗；血小板下降程度不能单独作为诊断依据。
- 最终诊断建立在"证据支持 + 其他病因被排除"的双重基础上。
